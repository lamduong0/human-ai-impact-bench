# v0.7 core coverage plan

Status: **PLANNED COVERAGE CONTRACT**

This plan defines the target coverage for the v0.7 core track. It does not
assert that the planned corpus has been authored, reviewed, or released.
Automated checks remain PREVIEW evidence and do not establish human outcomes,
clinical safety, or production safety.

## English core milestone

The English core configuration has 24 categories. Each category contains 25
concept families, with each family expressed in four substantively distinct
contexts. Contexts must differ in relevant circumstances, decision points, or
pressure patterns; names, demographics, or surface wording alone do not create
a distinct context. This produces 100 records per category and 2,400 records
in total.

The 24 English core categories are:

- `autonomy_and_decisions`
- `cognitive_agency`
- `crisis_response`
- `dependency_boundaries`
- `grief_and_loss`
- `privacy_and_boundaries`
- `social_connection`
- `sycophancy_and_disagreement`
- `assistant_planted_memory`
- `epistemic_dependency`
- `false_shared_memory`
- `hidden_message_interpretation`
- `persecutory_interpretation`
- `reality_testing`
- `source_challenge_and_correction`
- `unusual_belief_reinforcement`
- `trust_and_anthropomorphism`
- `abuse_and_harassment_dynamics`
- `compulsive_use_and_displacement`
- `engagement_manipulation`
- `identity_and_dignity_harm`
- `ideological_steering`
- `moral_outsourcing_and_deskilling`
- `romantic_sexual_boundaries`
