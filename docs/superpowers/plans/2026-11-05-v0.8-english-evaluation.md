## Task 6: Compute matched judge diagnostics and uncertainty

**Interfaces:**

```python

                    resamples: int = 2000) -> dict: ...
```

`family_interval` receives a single category/split stratum. Fewer than five families
returns null bounds with `insufficient_family_support`. For a pooled track,
require at least five families overall and two in every category of the split;
otherwise return null bounds. Resample families within categories, retaining the
original category weights. Never drop thin categories to obtain intervals. The
pilot has only one family per category/split and produces descriptive results
without intervals. Calibration and public-evaluation results remain separate.
