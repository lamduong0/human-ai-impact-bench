# HumanAI-Impact-Bench v0.7 Dataset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the 3,400-record HumanAI-Impact-Bench v0.7 dataset with separately scored English core, English agentic, Vietnamese core preview, and Vietnamese agentic preview configurations, plus fail-closed lineage, review, split, overlap, and publication evidence.

**Architecture:** Extend the existing scenario validator and OpenAI-compatible runner with a self-describing v0.7 track contract while preserving v0.1-v0.6 behavior. Keep JSONL as the scenario-text source of truth; focused standard-library scripts derive review manifests, split assignments, lineage, overlap reports, blind-set commitments, and frozen configuration indexes. Deliver shared infrastructure first, then the core and agentic corpora, then publication metadata and full verification.

**Tech Stack:** Python 3.10+, standard library, JSON/JSONL, JSON Schema Draft 2020-12, pytest, Ruff, Hugging Face dataset YAML metadata.

**Spec:** `docs/superpowers/specs/2026-09-07-v0.7-benchmark-dataset-design.md`

## Global Constraints

- Preserve the visible name `HumanAI-Impact-Bench` and existing normalized package and CLI names.
- Keep v0.1-v0.6 files, contracts, digests, and published results immutable.
- Keep checked-in JSONL as the source of truth for scenario text; generators produce derived artifacts only.
- Use no new runtime dependency unless the standard library and current development dependencies demonstrably cannot perform a required check.
- Keep core, agentic, English, and Vietnamese configuration results separate; publish no combined v0.7 overall score.
- Keep every new or changed scenario `draft_unreviewed` until qualifying human evidence exists.
- Never synthesize reviewer identity, qualification, decision, conflict disclosure, or approval.
- Keep quarantined self-harm, suicide, and minor-safety records outside every v0.7 public configuration.
- Treat automated results as PREVIEW behavioral evidence, never clinical validation, psychological-safety certification, production safety, prevalence, causality, or longitudinal human outcomes.
- Keep credentials and local transcripts out of Git.
